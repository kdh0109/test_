html : HTML 문서의 루트(최상위 요소)를 나타내므로 root 요소라고도 합니다. 다른 모든 요소는 이 요소의 자손이어야 합니다. <br>
head : 제목, 스크립트 및 스타일 시트와 같은 문서에 대한 기계 판독 가능 정보(메타데이터)를 포함합니다.<br>
link : 현재 문서와 외부 리소스 간의 관계를 지정합니다. 이 요소는 CSS에 연결하는 데 가장 일반적으로 사용되지만 무엇보다도 사이트 아이콘("Favicon" 스타일 아이콘과 홈 화면용 아이콘 및 모바일 장치의 앱)을 설정하는 데도 사용됩니다.<br>
meta : <base>, <link>, <script>, <style>, <title>과 같은 다른 메타관련 요소로 나타낼 수 없는 메타데이터를 내보냅니다.<br>
style : 문서 또는 문서의 일부에 대한 스타일 정보를 포함합니다. 이 요소를 포함하는 문서의 내용에 적용되는 CSS를 포함합니다.<br>
title : browser의 제목 표시줄 또는 페이지의 탭에 표시되는 문서의 제목을 정의합니다. 텍스트만 포함합니다. 요소 내의 태그는 무시됩니다.<br>
header : 소개 및 탐색에 도움을 주는 콘텐츠를 나타냅니다. 제목, 로고, 검색 폼, 작성자 이름 등의 요소도 포함할 수 있습니다.<br>
nav : 문서의 부분 중 현재 페이지 내, 또는 다른 페이지로의 링크를 보여주는 구획을 나타냅니다. 자주 쓰이는 예제는 메뉴, 목차, 색인입니다.<br>
hn : 6단계의 구획 제목을 나타냅니다. 구획 단계는 h1이 가장 높고 h6은 가장 낮습니다.<br>
main : 문서 <body>의 주요 콘텐츠를 나타냅니다. 주요 콘텐츠 영역은 문서의 핵심 주제나 앱의 핵심 기능에 직접적으로 연결됐거나 확장하는 콘텐츠로 이루어집니다.<br>
footer : 가장 가까운 섹션 콘텐츠나 섹션 루트의 푸터를 나타냅니다. 푸터는 일반적으로 섹션의 작성자, 저작권 정보, 관련 무서 등의 내용을 담습니다.<br>
section : HTML 문서의 독립적인 구획을 나타내며, 더 적합한 의미를 가진 요소가 없을 때 사용합니다. 보통 section은 제목을 포함하지만, 항상 그런 것은 아닙니다.<br>
article : 문서, 페이지, 애플리케이션, 또는 사이트 안에서 독립적으로 구분해 배포하거나 재사용 할 수 있는 구획을 나타냅니다. 사용 예제로 게시판과 블로그 글, 매거진이나 뉴스 기사 등이 있습니다.<br>
aside : 문서의 주요 내용과 간접적으로만 연관된 부분을 나타냅니다. 주로 사이드바 혹은 콜아웃 박스로 표현합니다.<br>
div : 유동 콘텐츠의 일반 컨테이너입니다. CSS를 사용하여 어떤 식으로든 스타일을 지정할 때까지 콘텐츠나 레이아웃에 영향을 미치지 않습니다.(예: 스타일이 직접 적용되거나 flexbox와 같은 일종의 레이아웃 모델이 적용됨) 부모요소).<br>
figure : 독립적인 콘텐츠를 표현합니다. <figcaption> 요소를 사용해 설명을 붙일 수 있습니다. 피규어, 설명, 콘텐츠는 하나의 단위로 참조됩니다.<br>
ul : 정렬되지 않은 목록을 나타냅니다. 보통 불릿으로 표현합니다.<br>
ol : 정렬된 목록을 나타냅니다. 보통 숫자 목록으로 표현합니다.<br>
li : 목록의 항목을 나타냅니다. 반드시 정렬 목록(ol), 비정렬 목록(ul), 혹은 메뉴(menu) 안에 위치해야 합니다. 메뉴와 비정렬 목록에서는 보통 불릿으로 항목을 나타내고, 정렬 목록에서는 숫자나 문자를 사용한 오름차순 카운터로 나타냅니다.<br>
p : 하나의 문단을 나타냅니다. 시각적인 매체에서, 문단은 보통 인접 블록과의 여백과 첫 줄의 들여쓰기로 구분하지만, HTML에서 문단은 이미지나 입력 폼 등 서로 관련있는 콘텐츠는 무엇이나 될 수 있습니다.<br>
a : href 특성을 통해 다른 페이지나 같은 페이지의 어느 위치, 파일, 이메일 주소와 그 외 다른 URL로 연결할 수 있는 하이퍼링크를 만듭니다. a 안의 콘텐츠는 링크 목적지의 설명을 나타내야 합니다.<br>
br : 텍스트 안에 줄바꿈(캐리지 리턴)을 생성합니다. 주소나 시조 등 줄의 구분이 중요한 내용을 작성할 떄 유용합니다.<br>
img : src를 활용하여 문서에 이미지를 넣습니다.<br>
video : 비디오 플레이백을 지원하는 미디어 플레이어를 문서에 삽입합니다. 오디오 콘텐츠에서도 사용할 수 있으나, audio 요소가 사용자 경험에 좀 더 적합합니다.<br>
table : 행과 열로 이루어진 표를 나타냅니다.<br>
caption : 표의 설명 또는 제목을 나타냅니다.<br>
thead : 테이블 열의 헤드를 정의하는 일련의 행을 정의합니다.<br>
tbody : 표의 여러 행 (tr)을 묶어서 표 본문을 구성합니다.<br>
tfoot : 테이블의 열을 요약하는 행들을 집합합니다.<br>
tr : 테이블의 셀 행을 정의합니다. 그런 다음 td(데이터 셀) 및 td(헤더 셀) 요소를 혼합하여 행의 셀을 설정할 수 있습니다.<br>
th : 테이블 셀 그룹의 헤더로 셀을 정의합니다. 이 그룹의 정확한 특성은 scope 및 headers 속성으로 정의됩니다.<br>
td : 데이터를 포함하는 표의 셀을 정의합니다. 이것은 표 모델에 참여합니다.<br>
button : 클릭 가능한 버튼을 나타냅니다. 버튼은 양식 내부는 물론 간단한 표준 버튼 기능이 필요한 곳이라면 문서 어디에나 배치할 수 있습니다. 기본값의 HTML 버튼은 사용자 에이전트의 호스트 플랫폼과 비슷한 디자인을 따라가지만, 외형은 CSS로 변경할 수 있습니다.<br>
form : 정보를 제출하기 위한 대화형 컨트롤을 포함하는 문서 구획을 나타냅니다.<br>
input : 웹 기반 양식에서 사용자의 데이터를 받을 수 있는 대화형 컨트롤을 생성합니다. 사용자 에이전트에 따라서 다양한 종류의 입력 데이터 유형과 컨트롤 위젯이 존재합니다. 입력 유형과 특성의 다양한 조합 가능성으로 인해, <input> 요소는 HTML에서 제일 강력하고 복잡한 요소 중 하나입니다.<br>
label : 사용자 인터페이스 항목의 설명을 나타냅니다.<br>
select : 옵션 메뉴를 제공하는 컨트롤을 나타냅니다.<br>
optgroup : select 요소의 옵션을 묶을 수 있습니다.<br>
option : select, optgroup, datalist 요소의 항목을 정의합니다. 그러므로, option을 사용해 팝업 메뉴 등 목록에서 하나의 항목을 나타낼 수 있습니다.<br>
output : 웹 사이트나 앱에서 계산이나 사용자 행동의 결과를 삽입할 수 있는 컨테이너 요소입니다.<br>
progress : 어느 작업의 완료 정도를 나타내며, 주로 진행 표시줄의 형태를 띕니다.<br>
textarea : 멀티라인 일반 텍스트 편집 컨트롤을 나타냅니다.<br>
CSS 선택자 : 선택자는 규칙 내부의 CSS 속성 값을 적용하기 위해 어떤 HTML 요소를 선택해야 하는지 브라우저에 알려주는 요소 및 기타 용어의 패턴입니다. 선택자에 의해 선택되는 요소를 선택자의 대상이라고 합니다. ex) h1{} .sec{} #sec{}....<br>
background-color : 배경색 변경 <br>
유효한 색상 이름 - 예: "빨간색",<br>
16진수 값 예:"#ff0000}<br>
RGB값 - 예: "rgb(255,0,0)"<br>
background-image : 배경이미지 삽입 ex) url(bgimg.jpg);<br>
backgound-repeat : 배경이미지 반복 ex) repeat, no-repeat, repeat-x, repeat-y<br>
background-attachment : 배경 이미지가 스크롤될지 아니면 고정될지(페이지의 나머지 부분과 함께 스크롤되지 않을지)를 지정합니다. ex) scroll, fixed, local, initial, inherit;<br>
background-position : 배경 이미지의 시작 위치를 설정합니다. ex) center, right center, center top<br>
color:DodgerBlue : 글자색 변경<br>
border : 요소 테두리의 스타일, 너비 및 색상을 지정할 수 있습니다.ex) 1px solid red;<br>
border-radius : 둥근 테두리를 추가하기 ex)5px, 5px 10px, 10px 20px, 10px 30px<br>
padding : 요소 테두리 안쪽, 즉 요소의 콘텐츠 주변에 여백을 만드는 데 사용 ex) 5px, 5px 10[x, 10px 20px 10px 30px<br>
height : 요소의 높이를 설정하는 데 사용<br>
width : 요소의 높이와 너비를 설정하는 데 사용<br>
CSS 박스 모델 : 웹 디자인 및 레이아웃을 논할 때 사용<br>
content - 텍스트와 이미지가 표시되는 상자의 내용<br>
padding - 콘텐츠 주변에 여백을 만듭니다. 패딩은 투명합니다.<br>
border - 패딩과 콘텐츠를 둘러싸는 테두리입니다.<br>
margin - 테두리 바깥쪽 영역을 비웁니다. 여백은 투명합니다.<br>
color : 텍스트의 색상을 설정<br>
색상 이름 - (예: "빨간색")<br>
16진수 값 - (예: "#ff0000")<br>
RGB 값 - (예: "rgb(255,0,0)")<br>
text-align : 텍스트를 가로 정렬로 설정 ex) center, right, left<br>
text-decoration : 텍스트에 장식선이 나타나는 모양을 제어하는 데 사용됩니다. ex) underline, none, overline<br>
font-style : 텍스트의 글꼴 스타일을 지정<br>
normal - 텍스트가 정상적으로 표시됩니다.<br>
italic - 텍스트는 이탤릭체로 표시됩니다.<br>
oblique - 텍스트가 기울어져 있습니다 (기울어진 글씨체는 기울임체와 매우 유사합니다.)<br>
font-size : 텍스트/글꼴의 크기를 지정하는 데 사용<br>
list-style : 단축 속성입니다. 하나의 선언으로 목록의 모든 속성을 설정<br>
position : 속성은 요소의 위치 지정 유형을 지정합니다.<br>
static - 이것이 기본 설정입니다. 요소는 일반적인 문서 흐름에 따라 배치됩니다.<br>
relative - 요소는 문서 흐름에서 원래 위치를 기준으로 배치됩니다.<br>
fixed - 요소의 위치는 뷰포트를 기준으로 지정됩니다.<br>
abolute - 요소는 가장 가까운 위치 지정된 상위 요소에 상대적으로 배치됩니다.<br>
sticky - 요소는 스크롤 위치에 따라 상대적 위치와 고정 위치 사이를 전환합니다.<br>
CSS위치 지정 속성 : left top right bottom<br>
z-index : 위치 지정된 요소의 스택 순서를 지정<br>
overflow : 영역에 맞지 않을 정도로 큰 콘텐츠에 어떤 처리를 할지 제어<br>
visible - 기본값입니다. 오버플로는 잘리지 않습니다. 콘텐츠가 요소의 박스 바깥쪽에 렌더링됩니다.<br>
hidden - 넘치는 부분은 잘리고 나머지 내용은 숨겨집니다.<br>
scroll - 스크롤바가 추가되었습니다. 사용자는 모든 콘텐츠를 보려면 스크롤을 해야 합니다.<br>
auto - 와 유사 scroll하지만, 필요할 때만 스크롤바를 추가합니다<br>
float 속성은 요소가 컨테이너 내에서 어떻게 떠 있어야 하는지를 지정<br>
*Flexbox는 CSS Flexible Box Layout 모듈의 줄임말<br>
display로 설정된 부모(컨테이너) 요소 flexinline-flex<br>
diplay:flex 반드시 또는 로 설정되어야 합니다. inline-flex<br>
justify-content : 플렉스 항목을 주축(가로)을 따라 정렬<br>
flex-direction : 플렉스 아이템의 표시 방향을 설정합니다.<br>
flex-wrap : 플렉스 항목이 줄바꿈될지 여부를 지정합니다.<br>
justify-content : 플렉스 아이템이 주축(가로)에서 사용 가능한 공간을 모두 사용하지 않을 경우 해당 아이템들을 정렬합니다.<br>
align-items : 플렉스 아이템이 세로 방향(교차축)으로 사용 가능한 공간을 모두 활용하지 않을 경우 해당 아이템들을 정렬합니다.<br>
align-content : 교차축에 여유 공간이 있고 플렉스 항목이 줄바꿈 될 때 플렉스 라인을 정렬합니다.<br>
Grid는 행과 열을 모두 사용하는 2차원 레이아웃에 사용<br>
그리드 컨테이너는 열과 행으로 배열된 하나 이상의 그리드 항목<br>
display:grid : 그리드 컨테이너가 됩니다.<br>
grid-template-columns : 그리드의 열 개수와 너비를 정의합니다.<br>
grid-template-rows : 그리드의 행 개수와 높이를 정의합니다.<br>
grid-template-areas : 명명된 그리드 항목을 사용하여 열과 행을 표시하는 방법을 정의합니다.<br>
gap : 그리드 컨테이너에서 행과 열 사이의 공간을 간격 (또는 여백) 이라고 합니다.<br>
justify-content : 주축(가로)에서 사용 가능한 공간을 모두 사용하지 않을 경우 그리드 콘텐츠를 정렬합니다.<br>
align-content : 가로축(세로)에서 사용 가능한 공간을 모두 사용하지 않을 때 그리드 콘텐츠를 정렬합니다.<br>
